LIFEOS - Hub d'organisation personnel

CONTENU
  index.html : l'application complete, autonome (aucune connexion requise).
  assets/    : les visuels (versions SVG integrees + tes images Canva importees).

UTILISATION
  1. Decompresse le ZIP ou tu veux.
  2. Double-clique sur index.html : LifeOS s'ouvre dans ton navigateur.
  3. Tes donnees sont sauvegardees automatiquement dans le navigateur (localStorage).
  Astuce : ecrase index.html par une version plus recente sans perdre tes donnees,
  elles restent dans le navigateur.

PERSONNALISATION
  - Mode nuit / blanc et accents (bleu, gris, dore, argente) via la barre du haut.
  - Bouton Visuels : importer tes propres images (logo, banniere, fond, illustrations).

PROCHAINE ETAPE (optionnel)
  Migration vers Next.js + Supabase pour un acces multi-appareils (meme pipeline
  que le Hub Courses : GitHub + Vercel + Supabase).
